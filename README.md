### ИнфоХимия

1. Найти датасет (1-3) по вашему направлению. Вы свободны в выборе, но! Чем интереснее и увлеченнее вы проведете аналитику — тем выше балл.
2. Всего вы должны проанализировать три случайные величины
    1. Нужно доказать, что это случайная величина (обосновать стохастическую природу данных. То есть показать, что значение нельзя вычислить детерминированно формулой)
    2. Если используете две величины одной природы события, то доказать их независимость (зависимость).
    3. Определить состоятельность оценок (показать эмпирически)
    4. EDA, нормализация
    5. Из генеральной совокупности взять выборку, по которой можно судить о генеральной. Проверить статистики генеральной и выборочной. Сделать выводы. Будьте внимательны, есть два подхода: с возвращением и без.
    6. Описана математическая база распределения и его особенности.
    7. Проверка минимум 1 гипотезы (успешно или нет; другие гипотезы можно проверять на одном датасете).
3. Создание генератора случайных чисел на основе одной из величин
    1. Проверка, что метрики реальных данных и генератора совпадают
    2. Использовать один из существующих подходов описанных в таблице или найти еще.
    3. Мат. Обоснование использованного метода
    4. Ссылки на материалы (много редких алгоритмов описаны в книгах, которых не найдете в интернете + балл за подбор литературы в библиотеках онлайн-журналах/базах статей (РГБ, РНБ, ИТМО, IEEE, ISO, ResearchGate))
    5. Минус за полную генерацию мат. Обоснования по распределению и генератору (видно, когда ход мысли сгенерировала нейронка, не только сам материал)

> **NB:** по датасетам уже существует аналитика. Желательно не читать ее до выполнения работы. Но! После выполнения исследования вы можете сослаться на уже сделанные ресерчи и подтвердить/опровергнуть свой ход мысли.
